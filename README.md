# Data Analyst Portfolio Website

## Project Overview

A professional portfolio showcasing data analytics skills,
technical education, operational achievements, and project work.

## Development Environment

- Editor: Visual Studio Code
- AI development assistant: Claude Code (optional)
- Languages: HTML5, CSS3, JavaScript
- Hosting target: GitHub Pages
- Dependencies: None

## Project Files

- index.html: Website content and structure
- styles.css: Design and responsive layout
- script.js: Mobile navigation and dynamic copyright year
- README.md: Documentation

## Design System

Theme: Midnight Navy + Emerald Green + Sky Blue + Royal Purple

- Background: #0b1220
- Surface: #111d30
- Card Surface: #18263a
- Primary Accent: #34d399 (Emerald Green)
- Transition Accent: #38bdf8 (Sky Blue)
- Final Accent: #7c3aed (Royal Purple)
- Gradient Direction: 110 degrees
- Gradient Stops: 0%, 50%, 100%

The design uses a dark technology-inspired color palette
with violet-purple highlights and electric-blue accents.

All visual styling is maintained in styles.css.
